# Финальный проект: сервис рекомендаций товаров (Retailrocket)

## Что где лежит и какой критерий закрывает

### Презентация
| Файл | Критерии |
|---|---|
| `recsys_presentation.pdf` | слайд 2: постановка задачи (рекомендации, бизнес-метрика «оборот», техническая метрика); слайд 3: описание данных (таблицы и типы); слайд 4: модель и логика; слайд 5: итоговое значение метрики (Precision@3 = 0,0148) |

### Документация
| Файл | Критерии |
|---|---|
| `service/README.md` | раздел 3 и 4: формат входных данных для обучения и факторы; раздел 4: трансформации датасета и построение валидации; раздел 5: эксперименты (тип модели, гиперпараметры, метрика); раздел 6 и 8: Docker-команды и устройство сервиса; раздел 7: API |
| `service/docker-build-instructions.md` | подробные команды сборки, запуска и экспорта образа |
| `service/docs/experiments.json` | полные результаты экспериментов |
| `feature_generation.ipynb` | анализ данных и генерация факторов |

### Докер-образ
| Файл | Критерии |
|---|---|
| `recsys-1.0.tar` | образ, экспортированный командой `docker save` |
| `service/Dockerfile`, `service/app/` | исходники сервиса: запуск из командной строки, запросы по документации, устойчивость к некорректным запросам (422), endpoint `/metrics` |
| `service/docker-compose.yml`, `service/monitoring/` | сервис вместе с Prometheus и Grafana |
| `report-docker.md` | описание того, как выполнен каждый пункт блока «Докер-образ» |

## Быстрый запуск (из этой папки)

```bash
docker load -i recsys-1.0.tar
docker run -d --name recsys -p 8000:8000 recsys:1.0
curl http://localhost:8000/health
curl http://localhost:8000/recommend/8
```

Подробности и остальные эндпоинты: `service/README.md`.

## Что не включено

Исходные данные (`events.csv`, `item_properties_*.csv`, `category_tree.csv`) и таблицы признаков `features/*.pkl` из-за размера не приложены. Они нужны только для переобучения (`python service/train.py`, запуск из корня проекта, где лежат эти файлы). Для запуска сервиса они не требуются: модель и таблицы признаков уже лежат в образе и в `service/artifacts/`.
